# Online Card Rate List 🃏

A fast, mobile-friendly **rate-list web app** for a print shop — customers can browse visiting-card / printing rates online.

- 📱 Mobile-first, works in any browser
- 🖨️ Built for PRINT POINT's real rate cards

Just open `index.html` in a browser, or deploy the folder to any static host.
